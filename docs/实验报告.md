## 故障与限制

1. 云主机只有约 3.5 GiB 内存，低于 doctor 要求的 4 GiB。该限制被保留记录，但实际构建、运行及门禁验证均成功。
2. Docker Hub 多次出现连接拒绝或超时，因此使用 `m.daocloud.io` 镜像代理，同时保留原镜像 digest。
3. 第一次安装构建工具时官方 Debian 软件源超过 600 秒，随后改用可访问的软件源。
4. 云主机对 `github.com` 的连接不稳定，但 `api.github.com` 可访问，因此仓库通过 bundle 转移至 Mac，并在 Mac 上完成 GitHub CI、分支保护和合并验证。
5. E6 属于课程 DRAFT 教学回放，候选来自保存的人工模型回答，不代表在线模型 API 调用或三个项目的完整基准测试。
